### GraphQLError

A GraphQLError describes an Error found during the parse, validate, or
execute phases of performing a GraphQL operation. In addition to a message
and stack trace, it also includes information about the locations in a
GraphQL document and/or execution result that correspond to the Error.

#### toString()

Returns this error as a human-readable message with source locations.

**Signature:**

<ApiSignature><span className="api-signature-name">toString</span>(): <span className="api-signature-keyword">string</span></ApiSignature>

##### Returns

| Type | Description |
| --- | --- |
| <ApiType><span className="api-signature-keyword">string</span></ApiType> | The formatted error string. |

##### Example

```ts
import { Source } from 'graphql/language';
import { GraphQLError } from 'graphql/error';

const error = new GraphQLError('Cannot query field "name".', {
  source: new Source('{ name }'),
  positions: [2],
});

error.toString(); // => 'Cannot query field "name".\n\nGraphQL request:1:3\n1 | { name }\n  |   ^'
```

## Functions

### locatedError()

Given an arbitrary value, presumably thrown while attempting to execute a
GraphQL operation, produce a new GraphQLError aware of the location in the
document responsible for the original Error.

**Signature:**

<ApiSignature><span className="api-signature-name">locatedError</span>(rawOriginalError: <span className="api-signature-keyword">unknown</span>, nodes: <a href="/api-v17/language/ast#astnode">ASTNode</a> | <span className="api-signature-keyword">readonly</span> <a href="/api-v17/language/ast#astnode">ASTNode</a>[] | null | <span className="api-signature-keyword">undefined</span>, path?: <span className="api-signature-type">Maybe</span>&lt;<span className="api-signature-keyword">readonly</span> (<span className="api-signature-keyword">string</span> | <span className="api-signature-keyword">number</span>)[]&gt;): <a href="/api-v17/error/errors#graphqlerror">GraphQLError</a></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| rawOriginalError | <ApiType><span className="api-signature-keyword">unknown</span></ApiType> | The original error value to wrap. |
| nodes | <ApiType><a href="/api-v17/language/ast#astnode">ASTNode</a> &#124; <span className="api-signature-keyword">readonly</span> <a href="/api-v17/language/ast#astnode">ASTNode</a>[] &#124; null &#124; <span className="api-signature-keyword">undefined</span></ApiType> | The AST nodes associated with the error. |
| path? | <ApiType><span className="api-signature-type">Maybe</span>&lt;<span className="api-signature-keyword">readonly</span> (<span className="api-signature-keyword">string</span> &#124; <span className="api-signature-keyword">number</span>)[]&gt;</ApiType> | The response path associated with the error. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v17/error/errors#graphqlerror">GraphQLError</a></ApiType> | The GraphQL error. |

#### Example

```ts
import { parse } from 'graphql/language';
import { locatedError } from 'graphql/error';

const document = parse('{ viewer { name } }');
const fieldNode = document.definitions[0].selectionSet.selections[0];
const error = locatedError(new Error('Resolver failed'), fieldNode, [
  'viewer',
]);

error.message; // => 'Resolver failed'
error.locations; // => [{ line: 1, column: 3 }]
error.path; // => ['viewer']
```

### syntaxError()

Produces a GraphQLError representing a syntax error, containing useful
descriptive information about the syntax error's position in the source.

**Signature:**

<ApiSignature><span className="api-signature-name">syntaxError</span>(source: <a href="/api-v17/language/source#source">Source</a>, position: <span className="api-signature-keyword">number</span>, description: <span className="api-signature-keyword">string</span>): <a href="/api-v17/error/errors#graphqlerror">GraphQLError</a></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| source | <ApiType><a href="/api-v17/language/source#source">Source</a></ApiType> | The GraphQL source containing the syntax error. |
| position | <ApiType><span className="api-signature-keyword">number</span></ApiType> | Character offset where the syntax error was encountered. |
| description | <ApiType><span className="api-signature-keyword">string</span></ApiType> | Human-readable description of the syntax error. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v17/error/errors#graphqlerror">GraphQLError</a></ApiType> | A GraphQLError located at the syntax error position. |

#### Example

```ts
import { Source } from 'graphql/language';
import { syntaxError } from 'graphql/error';

const error = syntaxError(new Source('query {'), 7, 'Expected Name');

error.message; // => 'Syntax Error: Expected Name'
error.locations; // => [{ line: 1, column: 8 }]
```

### GraphQLErrorExtensions

**Interface.** Custom extensions

**Remarks:** Use a unique identifier name for your extension, for example the name of
your library or project. Do not use a shortened identifier as this increases
the risk of conflicts. We recommend you add at most one extension field,
an object which can contain all the values you need.
