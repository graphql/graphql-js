# graphql/type/scalars

## Functions

### isSpecifiedScalarType()

Returns true when the scalar type is one of the scalars specified by GraphQL.

**Signature:**

<ApiSignature><span className="api-signature-name">isSpecifiedScalarType</span>(type: <a href="/api-v17/type/definitions#graphqlnamedtype">GraphQLNamedType</a>): <span className="api-signature-keyword">boolean</span></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| type | <ApiType><a href="/api-v17/type/definitions#graphqlnamedtype">GraphQLNamedType</a></ApiType> | The GraphQL type to inspect. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><span className="api-signature-keyword">boolean</span></ApiType> | True when the scalar type is one of the scalars specified by GraphQL. |

#### Example

```ts
import {
  GraphQLScalarType,
  GraphQLString,
  isSpecifiedScalarType,
} from 'graphql/type';

const DateTime = new GraphQLScalarType({
  name: 'DateTime',
});

isSpecifiedScalarType(GraphQLString); // => true
isSpecifiedScalarType(DateTime); // => false
```

### GRAPHQL_MAX_INT

Maximum possible Int value as per GraphQL Spec (32-bit signed integer).
n.b. This differs from JavaScript's numbers that are IEEE 754 doubles safe up-to 2^53 - 1
