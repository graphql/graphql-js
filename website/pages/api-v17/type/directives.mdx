### GraphQLDirective

##### Example

```ts
import { DirectiveLocation } from 'graphql/language';
import { GraphQLDirective, GraphQLString } from 'graphql/type';

const tag = new GraphQLDirective({
  name: 'tag',
  locations: [DirectiveLocation.FIELD_DEFINITION],
  args: {
    name: { type: GraphQLString },
  },
});

const config = tag.toConfig();
const tagCopy = new GraphQLDirective(config);

config.args.name.type; // => GraphQLString
tagCopy.args[0].name; // => 'name'
```

### isDirective()

Test if the given value is a GraphQL directive.

**Signature:**

<ApiSignature><span className="api-signature-name">isDirective</span>(directive: <span className="api-signature-keyword">unknown</span>): directive is GraphQLDirective</ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| directive | <ApiType><span className="api-signature-keyword">unknown</span></ApiType> | Value to inspect. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType>directive is GraphQLDirective</ApiType> | True when the value is a GraphQLDirective. |

#### Example

```ts
import { DirectiveLocation } from 'graphql/language';
import { GraphQLDirective, GraphQLString, isDirective } from 'graphql/type';

const upper = new GraphQLDirective({
  name: 'upper',
  locations: [DirectiveLocation.FIELD_DEFINITION],
});

isDirective(upper); // => true
isDirective(GraphQLString); // => false
```

### isSpecifiedDirective()

Returns true when the directive is one of the directives specified by GraphQL.

**Signature:**

<ApiSignature><span className="api-signature-name">isSpecifiedDirective</span>(directive: <a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a>): <span className="api-signature-keyword">boolean</span></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| directive | <ApiType><a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a></ApiType> | Directive to inspect. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><span className="api-signature-keyword">boolean</span></ApiType> | True when the directive is specified by GraphQL. |

#### Example

```ts
import {
  GraphQLDirective,
  GraphQLIncludeDirective,
  isSpecifiedDirective,
} from 'graphql/type';
import { DirectiveLocation } from 'graphql/language';

const customDirective = new GraphQLDirective({
  name: 'auth',
  locations: [DirectiveLocation.FIELD_DEFINITION],
});

isSpecifiedDirective(GraphQLIncludeDirective); // => true
isSpecifiedDirective(customDirective); // => false
```

### GraphQLDeferDirective

Experimental directive used to conditionally defer fragments.

This directive is exported for schemas that explicitly opt in to incremental
delivery. It is not included in [`specifiedDirectives`](/api-v17/type/directives#specifieddirectives).

<ApiType><a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a></ApiType>

### GraphQLStreamDirective

Experimental directive used to conditionally stream list fields.

This directive is exported for schemas that explicitly opt in to incremental
delivery. It is not included in [`specifiedDirectives`](/api-v17/type/directives#specifieddirectives).

<ApiType><a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a></ApiType>

### DEFAULT_DEPRECATION_REASON

Constant string used for default reason for a deprecation.

<ApiType>"No longer supported"</ApiType>

### GraphQLDeprecatedDirective

Used to declare element of a GraphQL schema as deprecated.

The `reason` argument is non-null and defaults to
[`DEFAULT_DEPRECATION_REASON`](/api-v17/type/directives#default_deprecation_reason).

<ApiType><a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a></ApiType>

### GraphQLSpecifiedByDirective

Used to provide a URL for specifying the behavior of custom scalar definitions.

<ApiType><a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a></ApiType>

### GraphQLOneOfDirective

Used to indicate an Input Object is a OneOf Input Object.

<ApiType><a href="/api-v17/type/directives#graphqldirective">GraphQLDirective</a></ApiType>

Full list of stable directives specified by GraphQL.js.

## Types

### GraphQLDirectiveExtensions

**Interface.** Custom extensions

**Remarks:** Use a unique identifier name for your extension, for example the name of
your library or project. Do not use a shortened identifier as this increases
the risk of conflicts. We recommend you add at most one extension field,
an object which can contain all the values you need.
