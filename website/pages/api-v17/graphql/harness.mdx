### GraphQLHarness

**Interface.** Overrides for the parse, validate, execute, and subscribe stages used by the
high-level `graphql` and [`graphqlSync`](/api-v17/graphql/request-pipeline#graphqlsync) request pipeline.

#### Members

| Name | Type | Description |
| --- | --- | --- |
| parse | <ApiType><a href="/api-v17/graphql/harness#graphqlparsefn">GraphQLParseFn</a></ApiType> | Parses GraphQL source text into a document AST. |
| validate | <ApiType><a href="/api-v17/graphql/harness#graphqlvalidatefn">GraphQLValidateFn</a></ApiType> | Validates a document AST against a schema. |
| execute | <ApiType><a href="/api-v17/graphql/harness#graphqlexecutefn">GraphQLExecuteFn</a></ApiType> | Executes a valid operation. |
| subscribe | <ApiType><a href="/api-v17/graphql/harness#graphqlsubscribefn">GraphQLSubscribeFn</a></ApiType> | Creates a response stream for a subscription operation. |
