# `graphql/error`

The `graphql/error` entry point contains the public error type and helpers used
by parsing, validation, execution, and application code that wants to report
GraphQL errors with source locations, response paths, or extension data.

```js
import { GraphQLError, locatedError, syntaxError } from 'graphql/error';
```

The same exports are also available from the root `graphql` entry point.

## `GraphQLError`

<ApiTag kind="deprecated-v16" title="Only the positional overload below is deprecated in v16." />

```ts
class GraphQLError extends Error {
  constructor(message: string, options?: GraphQLErrorOptions);

  // Deprecated in v16:
  constructor(
    message: string,
    nodes?: ASTNode | ReadonlyArray<ASTNode>,
    source?: Source,
    positions?: ReadonlyArray<number>,
    path?: ReadonlyArray<string | number>,
    originalError?: Error,
    extensions?: GraphQLErrorExtensions,
  );
}
```

Use `nodes` when the error belongs to GraphQL syntax, `path` when it belongs to
an execution response position, and `extensions` for application metadata.

## `syntaxError`

```ts
function syntaxError(
  source: Source,
  position: number,
  description: string,
): GraphQLError;
```

```js
import { Source, syntaxError } from 'graphql';

const source = new Source('query {', 'Example.graphql');
throw syntaxError(source, source.body.length, 'Expected Name, found <EOF>.');
```

## `locatedError`

```ts
function locatedError(
  originalError: unknown,
  nodes?: ReadonlyArray<ASTNode>,
  path?: ReadonlyArray<string | number>,
): GraphQLError;
```

`locatedError()` is mainly used by execution. If the original error is already
a located `GraphQLError`, GraphQL.js keeps the existing location data.

## Deprecated Formatting Helpers

`printError()` and `formatError()` are deprecated in v16. Use
`error.toString()` for the human-readable form and `error.toJSON()` for the
GraphQL response shape.

```js
const text = error.toString(); // instead of printError(error)
const json = error.toJSON();  // instead of formatError(error)
```
