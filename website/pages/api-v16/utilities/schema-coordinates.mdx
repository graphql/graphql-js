# graphql/utilities/schema-coordinates

## Functions

### resolveSchemaCoordinate()

A schema coordinate is resolved in the context of a GraphQL schema to
uniquely identify a schema element. It returns undefined if the schema
coordinate does not resolve to a schema element, meta-field, or introspection
schema element. It will throw if the containing schema element (if
applicable) does not exist.

https://spec.graphql.org/draft/#sec-Schema-Coordinates.Semantics

**Signature:**

<ApiSignature><span className="api-signature-name">resolveSchemaCoordinate</span>(schema: <a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a>, schemaCoordinate: <span className="api-signature-keyword">string</span> | <a href="/api-v16/language/source#source">Source</a>): <a href="/api-v16/utilities/schema-coordinates#resolvedschemaelement">ResolvedSchemaElement</a> | <span className="api-signature-keyword">undefined</span></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| schema | <ApiType><a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a></ApiType> | GraphQL schema to use. |
| schemaCoordinate | <ApiType><span className="api-signature-keyword">string</span> &#124; <a href="/api-v16/language/source#source">Source</a></ApiType> | The schema coordinate to resolve. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v16/utilities/schema-coordinates#resolvedschemaelement">ResolvedSchemaElement</a> &#124; <span className="api-signature-keyword">undefined</span></ApiType> | The schema element identified by the coordinate, or undefined if none exists. |

#### Example

```ts
import { buildSchema, resolveSchemaCoordinate } from 'graphql/utilities';

const schema = buildSchema(`
  directive @tag(name: String!) on FIELD_DEFINITION

  input ReviewInput {
    stars: Int!
  }

  enum Episode {
    NEW_HOPE
  }

  type Query {
    reviews(input: ReviewInput): [String] @tag(name: "reviews")
  }
`);

resolveSchemaCoordinate(schema, 'Query').kind; // => 'NamedType'
resolveSchemaCoordinate(schema, 'Query.reviews').kind; // => 'Field'
resolveSchemaCoordinate(schema, 'Query.reviews(input:)').kind; // => 'FieldArgument'
resolveSchemaCoordinate(schema, 'ReviewInput.stars').kind; // => 'InputField'
resolveSchemaCoordinate(schema, 'Episode.NEW_HOPE').kind; // => 'EnumValue'
resolveSchemaCoordinate(schema, '@tag').kind; // => 'Directive'
resolveSchemaCoordinate(schema, '@tag(name:)').kind; // => 'DirectiveArgument'
resolveSchemaCoordinate(schema, 'Query.missing'); // => undefined
```

### resolveASTSchemaCoordinate()

Resolves schema coordinate from a parsed SchemaCoordinate node.

**Signature:**

<ApiSignature><span className="api-signature-name">resolveASTSchemaCoordinate</span>(schema: <a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a>, schemaCoordinate: <a href="/api-v16/language/ast#schemacoordinatenode">SchemaCoordinateNode</a>): <a href="/api-v16/utilities/schema-coordinates#resolvedschemaelement">ResolvedSchemaElement</a> | <span className="api-signature-keyword">undefined</span></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| schema | <ApiType><a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a></ApiType> | GraphQL schema to use. |
| schemaCoordinate | <ApiType><a href="/api-v16/language/ast#schemacoordinatenode">SchemaCoordinateNode</a></ApiType> | The schema coordinate to resolve. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v16/utilities/schema-coordinates#resolvedschemaelement">ResolvedSchemaElement</a> &#124; <span className="api-signature-keyword">undefined</span></ApiType> | The schema element identified by the parsed coordinate, or undefined if none exists. |

#### Example

```ts
import { parseSchemaCoordinate } from 'graphql/language';
import { buildSchema, resolveASTSchemaCoordinate } from 'graphql/utilities';

const schema = buildSchema(`
  type Query {
    greeting(name: String): String
  }
`);
const coordinate = parseSchemaCoordinate('Query.greeting(name:)');
const resolved = resolveASTSchemaCoordinate(schema, coordinate);

resolved.kind; // => 'FieldArgument'
resolved.field.name; // => 'greeting'
resolved.fieldArgument.name; // => 'name'
```
