### ValidationContext

Validation context passed to query validation rules.

#### Constructor

Creates a ValidationContext instance.

**Signature:**

<ApiSignature><span className="api-signature-keyword">new</span> <span className="api-signature-name">ValidationContext</span>(schema: <a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a>, ast: <a href="/api-v16/language/ast#documentnode">DocumentNode</a>, typeInfo: <a href="/api-v16/utilities/type-info#typeinfo">TypeInfo</a>, onError: (error: <a href="/api-v16/error/errors#graphqlerror">GraphQLError</a>): <span className="api-signature-keyword">void</span>)</ApiSignature>

#### getSchema()

Returns the schema being used by this validation context.

**Signature:**

<ApiSignature><span className="api-signature-name">getSchema</span>(): <a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a></ApiSignature>

##### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v16/type/schema#graphqlschema">GraphQLSchema</a></ApiType> | The schema being validated against. |

##### Example

```ts
import { parse } from 'graphql/language';
import { buildSchema, TypeInfo } from 'graphql/utilities';
import { ValidationContext } from 'graphql/validation';

const schema = buildSchema(`
  type Query {
    greeting: String
  }
`);
const context = new ValidationContext(
  schema,
  parse('{ greeting }'),
  new TypeInfo(schema),
  () => {},
);

context.getSchema().getQueryType()?.name; // => 'Query'
```
