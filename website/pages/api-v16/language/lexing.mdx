# graphql/language/lexing

## Classes

### Lexer

Given a Source object, creates a Lexer for that source.
A Lexer is a stateful stream generator in that every time
it is advanced, it returns the next token in the Source. Assuming the
source lexes, the final Token emitted by the lexer will be of kind
EOF, after which the lexer will repeatedly return the same EOF token
whenever called.

#### advance()

Advances the token stream to the next non-ignored token.

**Signature:**

<ApiSignature><span className="api-signature-name">advance</span>(): <a href="/api-v16/language/ast#token">Token</a></ApiSignature>

##### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v16/language/ast#token">Token</a></ApiType> | The next non-ignored token. |

##### Example

```ts
import { Lexer, Source } from 'graphql/language';

const lexer = new Lexer(new Source('{ hello }'));
const token = lexer.advance();

token.kind; // => '{'
lexer.token; // => token
```

#### lookahead()

Looks ahead and returns the next non-ignored token, but does not change
the state of Lexer.

**Signature:**

<ApiSignature><span className="api-signature-name">lookahead</span>(): <a href="/api-v16/language/ast#token">Token</a></ApiSignature>

##### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v16/language/ast#token">Token</a></ApiType> | The next non-ignored token without advancing the lexer. |

##### Example

```ts
import { Lexer, Source } from 'graphql/language';

const lexer = new Lexer(new Source('{ hello }'));
const token = lexer.lookahead();

token.kind; // => '{'
lexer.token.kind; // => '<SOF>'
```
