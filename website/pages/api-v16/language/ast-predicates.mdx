## Functions

### isDefinitionNode()

Returns true when the AST node is a definition node.

**Signature:**

<ApiSignature><span className="api-signature-name">isDefinitionNode</span>(node: <a href="/api-v16/language/ast#astnode">ASTNode</a>): node is DefinitionNode</ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| node | <ApiType><a href="/api-v16/language/ast#astnode">ASTNode</a></ApiType> | The AST node to test. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType>node is DefinitionNode</ApiType> | True when the AST node is a definition node. |

#### Example

```ts
import { parse, isDefinitionNode } from 'graphql/language';

const document = parse('{ hello }');

isDefinitionNode(document.definitions[0]); // => true
isDefinitionNode(document); // => false
```
