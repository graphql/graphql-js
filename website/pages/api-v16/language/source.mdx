# graphql/language/source

## Classes

### Source

A representation of source input to GraphQL. The `name` and `locationOffset` parameters are
optional, but they are useful for clients who store GraphQL documents in source files.
For example, if the GraphQL input starts at line 40 in a file named `Foo.graphql`, it might
be useful for `name` to be `"Foo.graphql"` and location to be `{ line: 40, column: 1 }`.
The `line` and `column` properties in `locationOffset` are 1-indexed.

## Functions

### getLocation()

Takes a Source and a UTF-8 character offset, and returns the corresponding
line and column as a SourceLocation.

**Signature:**

<ApiSignature><span className="api-signature-name">getLocation</span>(source: <a href="/api-v16/language/source#source">Source</a>, position: <span className="api-signature-keyword">number</span>): <a href="/api-v16/language/source#sourcelocation">SourceLocation</a></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| source | <ApiType><a href="/api-v16/language/source#source">Source</a></ApiType> | The source document that contains the position. |
| position | <ApiType><span className="api-signature-keyword">number</span></ApiType> | The UTF-8 character offset in the source body. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><a href="/api-v16/language/source#sourcelocation">SourceLocation</a></ApiType> | The 1-indexed line and column for the given source position. |

#### Example

```ts
import { Source, getLocation } from 'graphql/language';

const source = new Source('type Query { hello: String }');
const location = getLocation(source, 13);

location; // => { line: 1, column: 14 }
```

### printLocation()

Render a helpful description of the location in the GraphQL Source document.

**Signature:**

<ApiSignature><span className="api-signature-name">printLocation</span>(location: <a href="/api-v16/language/ast#location">Location</a>): <span className="api-signature-keyword">string</span></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| location | <ApiType><a href="/api-v16/language/ast#location">Location</a></ApiType> | The AST location to print. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><span className="api-signature-keyword">string</span></ApiType> | A formatted source excerpt with line and column information. |

#### Example

```ts
import { parse, printLocation } from 'graphql/language';

const document = parse('type Query { hello: String }');
const location = document.definitions[0].loc;

if (location) {
  const printed = printLocation(location);

  printed; // => 'GraphQL request:1:1\n1 | type Query { hello: String }\n  | ^'
}
```
