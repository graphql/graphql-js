# `graphql`

The root `graphql` entry point exports the `graphql()` request function and
re-exports the public GraphQL.js v16 API from the original submodules. It is
the most convenient import path for applications, while the submodule pages in
this section document the same exports by area. You can import from the root
package or from individual modules such as `graphql/execution` and
`graphql/type`; the root package simply gathers those public exports in one
place.

```js
import { graphql, GraphQLSchema, parse, execute } from 'graphql';
```

## Request Entry Points

| Export | Kind | Description |
| --- | --- | --- |
| `graphql()` | Function | Parses, validates, and executes one GraphQL operation. Always returns a promise for one `ExecutionResult`. |
| `graphqlSync()` | Function | Runs the same pipeline synchronously and throws if a resolver returns a promise. |
| `GraphQLArgs` | Type | Object accepted by `graphql()` and `graphqlSync()`. |

```ts
function graphql(args: GraphQLArgs): Promise<ExecutionResult>;
function graphqlSync(args: GraphQLArgs): ExecutionResult;

interface GraphQLArgs {
  schema: GraphQLSchema;
  source: string | Source;
  rootValue?: unknown;
  contextValue?: unknown;
  variableValues?: { readonly [variable: string]: unknown } | null;
  operationName?: string | null;
  fieldResolver?: GraphQLFieldResolver<any, any> | null;
  typeResolver?: GraphQLTypeResolver<any, any> | null;
}
```

```js
const result = await graphql({
  schema,
  source: 'query Viewer($id: ID!) { viewer(id: $id) { name } }',
  variableValues: { id: '1' },
  contextValue: { currentUser },
});
```

In v17, `GraphQLArgs` also accepts parser, validation, execution, abort, and
harness options.

## Root Export Inventory

The root entry point re-exports all public values and types documented on the
submodule pages:

- [`graphql/error`](/api-v16/error): `GraphQLError`, `syntaxError`,
  `locatedError`, `printError` <ApiTag kind="deprecated-v16" />,
  `formatError` <ApiTag kind="deprecated-v16" />, and formatted error types.
- [`graphql/execution`](/api-v16/execution): `execute`, `executeSync`,
  `subscribe`, `createSourceEventStream`, default resolvers, argument helpers,
  execution result types, and `responsePathAsArray`.
- [`graphql/language`](/api-v16/language): parser, printer, visitor, source,
  token, AST, predicate, kind, token kind, and directive location exports.
- [`graphql/type`](/api-v16/type): schema constructors, built-in scalars,
  directives, introspection types, predicates, assertions, config types, and
  resolver types.
- [`graphql/utilities`](/api-v16/utilities): introspection, schema build and
  print, AST, type, input coercion, schema coordinate, and schema comparison
  utilities including `assertValidName()`, `isValidNameError()`, and
  `getOperationRootType()` <ApiTag kind="deprecated-v16" />.
- [`graphql/validation`](/api-v16/validation): `validate`, rule lists,
  `ValidationContext`, `ValidationRule`, and every exported validation rule.

For new code, prefer importing from `graphql` unless a tool specifically wants a
smaller submodule import.
