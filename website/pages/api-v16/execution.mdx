# `graphql/execution`

The `graphql/execution` entry point executes parsed GraphQL operations and
subscriptions. It also contains default resolvers and helpers for coercing
variables, field arguments, and directive arguments.

```js
import { execute, subscribe } from 'graphql/execution';
```

The same exports are also available from the root `graphql` entry point.

## Execution Exports

| Export | Kind | Description |
| --- | --- | --- |
| `execute()` | Function | Executes a query, mutation, or one subscription event and returns an `ExecutionResult` or a promise for one. |
| `executeSync()` | Function | Executes synchronously and throws if execution becomes asynchronous. |
| `defaultFieldResolver` | Function | Default field resolver. It reads a same-named property or calls a same-named method on the source value. |
| `defaultTypeResolver` | Function | Default abstract type resolver. It uses `__typename` first, then `isTypeOf` checks. |
| `responsePathAsArray()` | Function | Converts an execution response path linked list into an array. |
| `ExecutionArgs` | Type | Object accepted by `execute()`, `executeSync()`, `subscribe()`, and `createSourceEventStream()`. |
| `ExecutionResult` | Type | Standard GraphQL result with optional `data`, `errors`, and `extensions`. |
| `FormattedExecutionResult` | Type | JSON-serializable execution result shape. |

```ts
interface ExecutionArgs {
  schema: GraphQLSchema;
  document: DocumentNode;
  rootValue?: unknown;
  contextValue?: unknown;
  variableValues?: { readonly [variable: string]: unknown } | null;
  operationName?: string | null;
  fieldResolver?: GraphQLFieldResolver<any, any> | null;
  typeResolver?: GraphQLTypeResolver<any, any> | null;
  subscribeFieldResolver?: GraphQLFieldResolver<any, any> | null;
  options?: {
    maxCoercionErrors?: number;
  };
}
```

```js
import { execute, parse } from 'graphql';

const result = await execute({
  schema,
  document: parse('query { viewer { name } }'),
  contextValue: { currentUser },
});
```

`execute()` resolves successfully even when field errors occur; those errors
appear in the returned `ExecutionResult.errors` array.

## Subscription Exports

| Export | Kind | Description |
| --- | --- | --- |
| `subscribe()` | Function | Runs the full subscription pipeline and returns an async iterator of `ExecutionResult` values or one error result. |
| `createSourceEventStream()` <ApiTag kind="deprecated-v16" title="Only the positional overload is deprecated in v16." /> | Function | Runs only the source event stream phase of subscription execution. Prefer the object-argument form. |

```js
const streamOrResult = await subscribe({
  schema,
  document,
  contextValue,
});

if (Symbol.asyncIterator in Object(streamOrResult)) {
  for await (const result of streamOrResult) {
    send(result);
  }
}
```

`createSourceEventStream()` still accepts raw `ExecutionArgs` in v16. Passing
positional arguments to `createSourceEventStream()` is deprecated. Pass one
object instead.

## Argument, Variable, and Directive Helpers

| Export | Kind | Description |
| --- | --- | --- |
| `getVariableValues()` | Function | Coerces operation variable values and returns `{ coerced }` on success or `{ errors }` on failure. |
| `getArgumentValues()` | Function | Coerces argument values for a field or directive node. |
| `getDirectiveValues()` | Function | Coerces values for a directive usage and returns `undefined` when the directive is absent. |

```js
const result = getVariableValues(schema, variableDefinitions, rawVariables, {
  maxErrors: 20,
});

if (result.errors) {
  return { errors: result.errors };
}

const coercedVariables = result.coerced;
```

In v17, `getVariableValues()` returns `{ variableValues }` on success. The new
object preserves both source information and coerced runtime values; read
runtime values from `variableValues.coerced`.

## `graphql/subscription` <ApiTag kind="deprecated-v16" />

The `graphql/subscription` subpath exists only for v16 backwards
compatibility.

| Export | Kind | Description |
| --- | --- | --- |
| `subscribe()` | Function | Re-export of `graphql/execution` `subscribe()`. |
| `createSourceEventStream()` | Function | Re-export of `graphql/execution` `createSourceEventStream()`. |
| `SubscriptionArgs` <ApiTag kind="deprecated-v16" /> | Type | Deprecated alias of `ExecutionArgs`. |

```js
// Prefer this in v16 and v17:
import { subscribe } from 'graphql/execution';
```
