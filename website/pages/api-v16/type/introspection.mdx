# graphql/type/introspection

## Functions

### isIntrospectionType()

Returns true when the type is one of the built-in introspection types.

**Signature:**

<ApiSignature><span className="api-signature-name">isIntrospectionType</span>(type: <a href="/api-v16/type/definitions#graphqlnamedtype">GraphQLNamedType</a>): <span className="api-signature-keyword">boolean</span></ApiSignature>

#### Arguments

| Name | Type | Description |
| --- | --- | --- |
| type | <ApiType><a href="/api-v16/type/definitions#graphqlnamedtype">GraphQLNamedType</a></ApiType> | The GraphQL type to inspect. |

#### Returns

| Type | Description |
| --- | --- |
| <ApiType><span className="api-signature-keyword">boolean</span></ApiType> | True when the type is one of the built-in introspection types. |

#### Example

```ts
import { GraphQLString, isIntrospectionType, __Type } from 'graphql/type';

isIntrospectionType(__Type); // => true
isIntrospectionType(GraphQLString); // => false
```
